# XM8 1.0.0

First official release of the XM8 Buford for Gunner HEAT PC.

## What's in this version

- **New vehicle**: `XM8 Buford` registered as its own unit — it does not replace the vanilla T-80B.
- **XM291 120 mm gun** with the M1A2C ammunition set (M829E2 / M829E3 / M829E4 APFSDS, M830 / M830A1 HEAT) and a 30-round loadout with autoloader cycle.
- **Original running gear**: 6 road wheels per side, drive sprocket, idler, swing arms, skinned tracks with UV scrolling.
- **Level III composite add-on armour**: 109 separately armoured plates with per-plate KE/CE RHAe, correct hull / turret / gun attachment (gun plates elevate with the barrel), semi-transparent AAR visuals, and a preference to run the bare hull instead.
- **Interior and damage model**: X-ray interior parts plus damage zones for engine, transmission, turret drives, breech, barrel, autoloader, sights, machine guns and flammable fuel tanks.
- **Green base paint** reworked to match the game's palette while keeping panel detail and darkening the running gear rubber.
- **Handling and drives**: 580 hp / 2400 rpm, 21.0 t bare / 25.8 t with the L3 kit, 72 km/h forward, 27 km/h reverse, 40°/s traverse, 14°/s elevation, −8° to +20° limits.
- **Camera and weapon alignment**: third-person centre on the model, commander view on the cupola hatch, co-axial muzzle aligned and elevating with the gun.

## Install

Extract the `XM8` folder into `<GHPC install>\Bin\Mods` (MelonLoader 0.7.x / net472).

## Known limitations

- Only the olive green paint is included; sand and NATO variants are not implemented yet.
- The add-on armour plates use single-skin collision meshes; extremely oblique hits at plate edges can behave slightly differently from the visual outline.
